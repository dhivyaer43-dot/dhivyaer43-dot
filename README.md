## 🕵️ Dark Pattern Detector – Chrome Extension (Mini Project, Zeroth Review)

A Chrome browser extension, built with a teammate, that detects manipulative UI/UX "dark patterns" while you browse. It scans page content, flags tactics like **false urgency, hidden costs, forced subscriptions and confirmshaming**, and highlights them directly on the page with a severity-scored report.

- 🔍 **Approach:** rule database built around a published dark-pattern taxonomy (False Urgency, Hidden Costs, Forced Continuity, Confirmshaming), with regex and rule-based pattern matching
- 🧪 **Validation:** detection logic tested on real e-commerce sample text before trying live webpages
- 🤖 **NLP/ML extension:** Python, scikit-learn, NLTK/spaCy

**Tech Stack**

`JavaScript (ES6)` `HTML5` `CSS3` `Chrome Extension (Manifest V3)` `Python` `scikit-learn` `NLTK / spaCy` `Flask` `SQLite` `Git`

## 🩺 MediSetu – AI Health Triage Assistant (Prasunethon 2.0)

A multilingual, voice-first AI health triage assistant for rural India, built for the **Prasunethon 2.0 Hackathon**. Every recommendation explains *why*, not just *what*, so patients can trust it.
